Как отправить карточки клиентам?

Поскольку вы работаете в приватном редакторе, прямая ссылка из браузера временно недоступна для внешних пользователей. Вот 2 простых способа передать гайд:

1. Отправить файл HTML Самый простой

Скачайте исходный файл index.html и отправьте его клиенту в Telegram или WhatsApp. Он откроется в браузере телефона без ошибок.

2. Опубликовать как онлайн-ссылку

Загрузите файл на бесплатный хостинг (например, Netlify Drop) за 30 секунд, и у вас появится вечная ссылка для соцсетей!
